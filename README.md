# Leave Managament
An ASP.NET Core MVC app for managing leave types (e.g. "Sick Leave", "Annual Leave"), built as a training project

## Tech stack

- ASP.NET Core MVC
- Entity Framework Core (SQL Server / LocalDB)
- AutoMapper (entity ↔ view model mapping)
- Bootstrap (default MVC template styling)

## Features

- Full CRUD for Leave Types : list, create, view details, edit, delete
- Server-side + client-side validation (required fields, name length, days range)
- Duplicate-name check on create/edit
